# PCLPatcher

PCL（Plain Craft Launcher）下载功能一键恢复补丁工具。目标版本：**官方 PCL 2.99.0.0（正式版 413）**。

官方程序中 Minecraft 下载、安装、整合包相关功能因编译期限制被裁剪。本工具通过 **IL 移植**在你机器上的官方 EXE
现场恢复这些功能：不重实现、不重编译、不联网上传任何文件；官方 EXE 内置的各项配置原样保留。

> 本项目与 PCL 官方无关。仅供个人学习研究使用，请遵循《PCL 分发有限许可》，请勿用于商业用途或再分发打补丁后的程序。
> 本工具不分发 PCL 程序本体——补丁始终基于你自己电脑上的官方 EXE 现场生成。

---

## 用法一：直接替换（手上已有补丁版启动器时）

1. **⚠️ 先备份你的官方原版启动器**：把 `Plain Craft Launcher 2.exe` 复制一份改名存放（例如
   `Plain Craft Launcher 2 - 官方原版备份.exe`）。万一补丁版有问题，改回原名即可还原。
2. 用补丁版启动器覆盖原文件（放在原文件夹内替换，原有的 `PCL` 数据文件夹、`.minecraft`、版本设置全部保留）。
3. 想还原时，把备份文件改回原名覆盖回去即可。

## 用法二：现场打补丁（推荐）

1. 从 [Releases](../../releases) 下载 `PCLPatcher.exe`。
2. 把它放到官方启动器 `Plain Craft Launcher 2.exe` **旁边**（同一文件夹）。
3. 双击运行，工具会自动完成一切：
   - **环境检测**（6 项）：参考程序就绪、启动器存在、是否已打过补丁、版本号必须为 2.99.0.0、
     启动器是否正在运行（运行中会提示先退出）、文件是否被占用（含杀毒软件扫描锁定）。
     任何一项不通过都会弹窗说明原因并退出，**原文件不做任何改动**。
   - **预打补丁**：全部在内存中完成并写入临时文件，随后逐指令校验；失败则清理临时文件退出。
   - **二次确认**：弹窗说明将执行的改动，你确认后才会真正替换。
   - **替换**：官方版自动改名备份为「官方原版备份 - Plain Craft Launcher 2.exe」（逐字节等于原版），
     补丁版占用原文件名；中途出错自动回滚，失败时在工具旁生成错误日志文件。

命令行方式：`PCLPatcher.exe [启动器路径] [--auto]`（`--auto` 跳过弹窗自动确认）。

## 打完补丁后

- 文件夹里会有两个 exe：`Plain Craft Launcher 2.exe`（补丁版）+ `官方原版备份 - ...`（官方原版），**备份请保留**。
- **不要让 PCL 自动更新**：更新会下载新官方 EXE 覆盖补丁版，下载功能恢复原状；新版本发布后需等本工具跟进。
- 想还原：把备份文件改回原名即可。

## 恢复的功能

| 功能 | 说明 |
|---|---|
| 原版版本列表 / 下载 / 安装 | 安装原版页恢复正常加载 |
| Forge / NeoForge / Fabric / OptiFine / LiteLoader | 安装选择页全量可用 |
| 一键安装 | 主页启动按钮无版本时的下载安装链路 |
| 整合包安装 | 本地导入、按钮入口、拖入主窗口、资源页详情"点击安装" |
| 游戏文件补全 / 修复 | 版本修复功能（官方版本就完整） |
| 版本修改页更换原版版本 | "原版 Minecraft"卡片恢复可见 |

## 工作原理（简述）

VB 编译器对 `Const RestrictMcDownload = True` 做编译期常量折叠：受限分支保留、正常分支连同调用点被消除，
但**孤立的方法本体仍完整留在官方 EXE 中**。本工具内嵌一个 `RestrictMcDownload = False` 的同版本参考程序，
用 dnlib 把 5 个被裁剪的方法体（连同局部变量、异常处理子句）按成员名重导入后移植回官方 EXE，再逐指令校验。
任何一步解析或校验失败都会整体中止，不会产生半打状态。详见 [src](./src)。

## 从源码构建

```powershell
cd src
dotnet build            # .NET SDK（产物为 PCLPatcher.exe + dnlib.dll）
# 单文件发布：ILRepack 合并 dnlib 后，用 embedref 模式内嵌参考程序（见仓库历史/说明）
```

`src` 中不含参考程序本体（约 5.9 MB，需用 PCL 2.99.0.0 开源源码在
`E:\Projects\PCL\本体代码\` 路径镜像下构建，细节见源码内注释）。
